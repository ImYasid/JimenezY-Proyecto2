# Servicio-Integrado-de-Directorio-y-Autentificaci-n
S.I.G.A.L. es un sistema de identidad centralizada para la FIS-EPN. Mediante Kerberos y LDAP, gestiona el acceso a laboratorios según el código único y horarios de clase. Permite auditar daños físicos vinculando cada PC con el estudiante y profesor responsable en turnos de 07:00 a 20:00.
